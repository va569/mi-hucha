# Mi Hucha

App para organizar gastos, ingresos, gastos fijos, deudas y ahorro para metas.

**Abrir la app:** https://va569.github.io/mi-hucha/

En el iPhone: ábrela en Safari → Compartir → **Añadir a pantalla de inicio**. Funciona sin conexión.

Los datos se guardan solo en el dispositivo de cada persona. Este repositorio contiene únicamente el código de la app.
